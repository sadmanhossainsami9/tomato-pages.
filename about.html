About the project

Tomato Leaf Disease Classification Using Machine Learning is a project that teaches a computer to recognize common tomato leaf diseases from a photo.

Why this project

Tomato plants can be hit by several leaf diseases, and many of them look alike in the early stages. Farmers and gardeners often notice the problem late, when it has already spread to other plants and lowered the harvest.

This project explores whether a machine learning model can help by looking at a photo of a leaf and suggesting which disease it may have, so that the problem can be checked and handled sooner.

Project goals

What the project sets out to do.

Classify diseases

Tell apart common tomato leaf conditions, including healthy leaves, from a single photo.

Make it simple to use

Let anyone upload a photo on a phone or computer and read the result without technical knowledge.

Share knowledge

Pair each result with clear information about the disease, its symptoms and ways to reduce it.

What this website offers

Diseases

A guide to each disease the project covers, with photos, causes and prevention tips.

Disease Detection

Upload a leaf photo and see the predicted disease with a confidence score.

Methodology

How the model is built and how a scan works on this site.
